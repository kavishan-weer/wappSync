# Landing Page Specification

## Goal

Create a WhatsApp-themed landing page for a affordable AI automation tool for online shop owners. The page should clearly explain what the software does, who it is for, why it is useful, and how shop owners can get started.

The page should feel simple, friendly, trustworthy, and modern.

### 11. FAQ Section

#### Question Answer

Does this replace WhatsApp? It connects to WhatsApp Business API and gives you a dashboard inbox.
Can AI answer product questions? Yes, using your product catalog and uploaded policies.
What happens if AI is unsure? The chat is marked as “Needs attention” and the owner is alerted.
Can it create orders? Yes, it collects customer details and creates orders in the dashboard.
Do I need Shopify? No. Products can be added manually.
Is payment integration included? No, payments are out of scope for MVP.

### Landing Page Content Rules

- Use simple language.
- Do not overuse technical terms like RAG, embeddings, or vector database.
- Explain AI as “answers using your shop information”.
- Keep the page focused on online shop owners.
- Make WhatsApp the main visual inspiration.
- Use green only for CTAs, highlights, and sent message bubbles.
  Keep sections spacious and clean.
  Every section must support one goal: converting shop owners to try the product.
